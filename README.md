# Tattva App, Golden Dawn Western, version 1

Frontend only, for now. 25 cards: 5 singles and 20 mixed doubles.
English name first, Sanskrit second. Labelled Golden Dawn Western Tattva, not Hindu Tattva.

Images in this index.html are embedded as data URIs, so the page shows
all 25 cards on its own, without a separate images folder.
The separate images/ and icons/ folders from the local PWA build can be
uploaded later via the GitHub website if full offline caching is wanted.
No Indian branch material is in version 1.
